Список камер

Подключённый диск

Выберите существующий раздел ext4 или exFAT. Форматирование не выполняется. При заполнении до 90 % старые записи удаляются до освобождения 15 % диска.

Хранение записей на диске

Лимит учитывает всё занятое место на выбранном диске. При его достижении Dozor удаляет свои записи от старых к новым. Проверка выполняется каждые 15 секунд.

Записи «Перед отключением» сохраняются в приоритете 3 месяца (90 дней) после отключения камеры. Если остальных записей не осталось, удаляются и они — начиная с самых старых. Через 90 дней записи участвуют в обычной очистке.

Заполнение диска пока неизвестно

Целое число от 1 до 99. По умолчанию — 80%.

Облачная копия в S3

Очистка диска не удаляет облачные копии. Срок хранения в S3 задаётся lifecycle-правилом бакета.

Введите ключи доступа к бакету.

КиБ/с

0 — без ограничения

Версия Dozor

По умолчанию проверяются релизы Jourloy/dozor. Ключ проверки подписи устанавливается администратором на устройстве.

Если есть новая версия, установим её сразу. Работает и при выключенном автообновлении. На время установки запись будет приостановлена.
